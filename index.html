GeoVista 隐私政策

更新及生效日期：2026 年 9 月 29 日
适用应用：GeoVista（com.geovista.app）

GeoVista 是由个人开发者（GitHub 账号 radiofor，以下简称“我们”）提供的桌面地理信息工具，用于地理数据浏览、编辑、可视化与空间分析。本政策说明应用在本地处理文件、使用网络资源以及接收用户反馈时如何处理信息。

1. 本地数据处理

GeoVista 无需注册应用账号。打开、显示、编辑、分析和导出地理数据的核心操作在设备本地完成；这些操作不会主动将所选数据文件上传给开发者。应用未设置用于收集地理数据的开发者服务器，未集成广告或用户行为统计功能。

  • 为实现数据处理，应用读取您选择的栅格、矢量和项目文件，包括其中的几何坐标、影像、属性、坐标参考及文件路径；属性和文件内容可能包含您自行提供的个人信息。
  • 应用保存项目配置、显示设置、窗口状态、已授权目录记录及必要的缓存，用于恢复界面、访问已授权文件和提高地图显示速度。
  • 保存或导出时，应用向您指定的位置写入结果。若您选择系统提供的同步目录或其他存储服务，其同步行为受该服务的设置和政策管理。

2. 文件授权与设备权限

  • 网络访问（INTERNET）：用于请求网络地图资源和下载坐标转换所需的投影格网文件。
  • 文件持久授权（FILE_ACCESS_PERSIST）：在您通过系统文件选择器明确授权后，保持对所选目录的访问，以便再次加载、编辑和保存数据。该授权不等于访问设备上的全部文件。您可在应用的授权目录管理界面移除对应目录授权。

当前版本未声明设备定位、相机、麦克风或通讯录访问权限。地理文件中的坐标及当前浏览的地图范围，不等同于通过设备定位获取您的实际位置。

3. 网络请求与第三方服务

使用联网功能时，相应服务方能够接收到您的网络连接 IP 地址、请求时间、所请求的资源路径及必要的请求头。GeoVista 不将本地数据文件作为地图瓦片请求或投影格网下载的请求内容发送。

  • 网络地图：加载网络图层时，应用向所选地图的资源服务方发送瓦片坐标、缩放级别及必要的样式参数，并发送标识应用的 User-Agent。服务方可以由瓦片请求判断所浏览的地图区域。移动、缩放地图或恢复包含网络图层的项目时，可能继续请求相应资源。
  • 服务提供方：当前地图目录包括腾讯、百度、高德、GeoQ、Esri、Google、Microsoft Bing、OpenStreetMap 及相关专题地图、EOX、NASA GIBS、USGS、Waze、Mapzen/Tilezen 等来源。实际接收方取决于您加载的图层及其资源地址，并非每次使用都会连接所有服务。各服务可能由其运营方或内容分发网络提供。
  • 投影格网下载：当坐标转换缺少所需格网且您选择下载时，应用请求 cdn.proj.org 上相应的格网文件；请求中包含格网文件名，不包含您正在处理的原始地理数据文件。您也可以选择从本地导入格网文件。
  • 本政策页面：本页面通过 GitHub Pages 托管。访问页面时，GitHub 可按其隐私声明处理访问日志及网络信息。本页面自身未添加广告、统计脚本或表单。

第三方服务可能在中国境内或境外提供服务，其服务器位置、访问日志保存期限及处理规则由相应服务方确定。我们不将这些第三方日志描述为由开发者统一保存在境内，也无法代替服务方删除其日志。您可停止使用并移除相应网络图层；本地文件的浏览与处理不要求加载网络地图。

4. 存储、备份及保留期限

用户文件和导出结果保存在您选择的位置，通常保留至您主动删除。应用设置、目录授权记录、投影格网及缓存保存在设备的应用存储中，供持续使用；缓存可能因清理、过期或系统管理而更新或移除。应用运行中产生的诊断信息由本机日志机制管理，当前未设置向开发者自动上传日志的功能。

应用启用了 HarmonyOS 系统备份与恢复支持。系统是否备份、迁移或恢复应用数据，取决于设备上的系统功能、您的操作及相关设置；这些行为不等于开发者接收了您的备份。备份副本的存储与删除由相应系统服务管理。

清除应用数据或卸载应用时，应用私有数据的清理由系统执行；您保存在公共目录、其他存储服务中的原始文件、项目和导出结果，以及系统备份，不会因此保证同时删除，需要分别管理。

5. 您如何管理信息

  • 您可以选择打开哪些文件，编辑、导出或通过文件管理器删除自己保存的数据。
  • 您可以在应用中移除目录授权；移除授权不会删除该目录中的文件。
  • 您可以移除网络图层，停止相应地图请求，并在缺少格网时选择本地导入或取消操作。
  • 您可以通过设备的应用管理和备份设置管理本地应用数据及备份。GeoVista 没有应用账号，因此不提供账号注销流程。
  • 对于您主动发送给我们的反馈信息，可通过下方联系方式请求查阅、更正或删除；对于开发者不持有的本地文件及第三方日志，我们无法直接代为操作。

6. 反馈与信息安全

如果您主动通过邮箱或 GitHub Issues 联系我们，我们会接收到您提供的联系信息、问题描述及附件，用于处理反馈。请仅提供排查问题所必需的信息，不要在公开 Issues 中发布个人信息、密码或未脱敏的地理数据。反馈信息仅在处理问题及必要后续沟通期间保留；您可提出删除请求，邮件平台和 GitHub 上的副本还受相应平台规则管理。

我们不出售用户个人信息。请保护设备账户及文件访问权限。应用使用的网络服务中既有 HTTPS 地址，也可能有 HTTP 地址；HTTP 不提供传输加密保护。本地文件及项目未因使用 GeoVista 而自动获得额外的应用层加密。

7. 未成年人

本应用并非专门面向儿童设计。未成年人应在监护人的指导下使用，并避免在数据文件或反馈中提供不必要的个人信息。监护人如发现未成年人向开发者提供了需要删除的信息，可通过下方方式联系我们。

8. 政策更新与联系

功能或信息处理方式发生变化时，我们会更新本政策及更新日期。涉及重要变化时，将通过适当方式告知用户。
